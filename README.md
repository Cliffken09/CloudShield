# CloudShield

A secure, containerized and cloud-ready password vault prototype.

## Purpose

CloudShield is a learning project focused on exploring:

- Cloud infrastructure
- Cybersecurity
- Networking
- Linux
- Containerization
- System design
- Secure application development

The vault will only contain dummy credentials and must never be used to store real passwords.
